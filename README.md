# Linear Regression from Scratch

Predicting food delivery time (in minutes) with linear regression, implemented three ways and compared:

1. **scikit-learn** `LinearRegression`
2. **Normal equation (OLS)** solved directly with NumPy: `b = (XᵀX)⁻¹Xᵀy`
3. **Gradient descent** written from scratch with NumPy

All three should reach essentially the same R² on the train and test sets.

## Dataset

`delivery_times.csv` is a synthetic dataset of 600 deliveries, generated by `make_data.py` (seed 7).

| Feature | Description |
|---|---|
| `distance_km` | Delivery distance |
| `n_items` | Number of items in the order |
| `traffic_index` | Congestion level (1–10) |
| `is_raining` | 1 if raining, else 0 |
| `courier_exp_months` | Courier experience in months |
| `delivery_min` | **Target**: delivery time in minutes |

## Approach

- 80/20 train/test split (`random_state=42`)
- Standardise the continuous features with `StandardScaler` (fit on train only; the binary `is_raining` is left as is)
- Fit with each of the three methods and report R² on train and test

## Files

- `code.ipynb`: the full walkthrough
- `make_data.py`: generates the dataset
- `delivery_times.csv`: the data
